# Security Policy

This repository mirrors signed artifacts built by
[`zetic-ai/melange-cli`](https://github.com/zetic-ai/melange-cli). Source fixes
and security patches are made upstream.

Report suspected vulnerabilities privately to
[tony@zetic.ai](mailto:tony@zetic.ai), following the
[upstream security policy](https://github.com/zetic-ai/melange-cli/security/policy).
Do not disclose vulnerabilities in public issues or pull requests.
